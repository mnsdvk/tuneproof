Every speedup is a claim. Prove it.

An agent that speeds up an OpenCV 5 vision pipeline and refuses any speedup that quietly breaks the output. This page is an interactive viewer of a recorded run on AWS EC2 (). It does not run the tuner live; to re-run it: python -m coolpilot.run --images 6 --repeats 3 --grid. Code and tests: github.com/mnsdvk/tuneproof.

The quality guard

A change is accepted only if the output agrees with the baseline output (F1 ≥ ), the ground-truth F1 drops no more than , and it is at least 2% faster.

Limitations

  • Synthetic data (6 images, 1024×1024). The underlying detector is modest (ground-truth F1 0.68).
  • The threads=1 step was accepted for a 2.3% gain, which is within measurement noise. The real gain is the background setting.
  • The residual stage (about 64% of runtime after tuning) could not be reduced without failing the guard.
  • The planner is rule-based, not an LLM. COOL and Graviton were not used or evaluated.
